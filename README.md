# BannerOfBones

Unity project repository for **BannerOfBones**.

## Unity Version

- `2022.3.62f1` (from `ProjectSettings/ProjectVersion.txt`)

## Project Setup

1. Install Unity Hub.
2. Install Unity Editor `2022.3.62f1`.
3. In Unity Hub, choose **Add project from disk**.
4. Select this repository folder:
   - `/home/runner/work/LichLord/LichLord`
5. Open the project and allow package import/compilation to complete.

## Notes

- This repository already includes standard Unity ignore rules in `.gitignore`.
- Unity package dependencies are managed through `Packages/manifest.json`.
